# F26-NSDC-Data-Visualization
Welcome! This is the GitHub repository for Anthony's F26 NSDC Data Visualization project, intended as a centralized place for you all to do work. GitHub is a platform that works with Git to host repositories in the cloud, and a repository is a place where code is stored. By creating a repo in GitHub, users are able to work collaboratively with others.

## To Begin
To begin, I would recommend creating some kind of folder on your computer for where you put code repositories. I have a Windows laptop, and I personally have my repos saved in `C:\Users\amui\source\repos`, but realistically, anywhere works. Alternatively, you can open your Terminal and run `mkdir repos` or `mkdir -p source/repos`. Or if you want to name it differently, go for it. What's more important is that this folder exists and you remember where on your computer it is. 

Next, you're going to want to clone this repo. If you don't have your Terminal open, open the Terminal, and you're going to run `cd (INSERT FILE PATH HERE)`. So for me, I would run `cd C:\Users\amui\source\repos`. This may be different for Mac users, and the name will almost certainly be different, but just put what the file path is. Alternatively, to get the file path, find the folder in your File Explorer, right click, and press "Copy as path". 

Afterwards, you're going to want to make sure that Git is installed. Hopefully, you've done this already. If you have, you're going to enter `git clone https://github.com/antmui1/F26-NSDC-Data-Visualization.git`. Assuming everything is configured, it should copy everything from this repo into a folder in your repos folder.
